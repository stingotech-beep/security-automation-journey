# Government NIST 800-53 Compliance Mapper

Automated compliance auditing for government systems.

## Dataset
- Simulated system configurations (200 controls)
- NIST 800-53 controls: AC-2, AU-6, CM-2, IA-2, SC-7, SI-4

## Compliance Logic
- Maps system configs to NIST controls
- Calculates overall compliance percentage
- Flags critical failures (IA-2, SC-7)
- Exports audit-ready CSV report

## SPAA Pillars
- **Security:** NIST 800-53, government compliance, audit frameworks
- **Python:** CSV parsing, control mapping, scoring algorithms
- **Analytics:** Compliance scoring, failure clustering, trend analysis
- **Automation:** One-command audit report generation
