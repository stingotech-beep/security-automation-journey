# Fintech Fraud Detector (SPAA Project)

Real-time transaction anomaly detection using Python + Pandas.

## Dataset
- Kaggle: Credit Card Fraud Detection
- 284,807 transactions, 492 fraud cases

## Versions
- v1: Load CSV, print first 5 rows, basic stats
- v2: Anomaly scoring + risk flags
- v3: Automated alerts + dashboard
